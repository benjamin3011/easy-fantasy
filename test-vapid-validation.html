Expected Format

Valid VAPID Key Requirements:
• Length: ~88 characters (base64url encoded)
• Format: Base64url encoding of 65-byte uncompressed public key
• Starts with 0x04 when decoded (uncompressed point format)
• Example: BKxvxhTlKG-Jm8CNWi_F-e_lVrKWM8OcF6Jk2QZ8jY9X4vQ2sP3nR7wE5tA9cB1dF6gH8iJ0kL2mN4oP6qR8sT0u
